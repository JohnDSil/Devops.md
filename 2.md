2.- Fases de DevOps
El ciclo de vida de DevOps se representa como un bucle infinito que conecta desarrollo y operaciones de forma continua:

Plaintext
       .--- Plan ---> Code ---> Build ---.
      /                                   \
     |                                     v
   Monitor                              Test
     ^                                     |
      \                                   /
       '--- Operate <-- Deploy <-- Release '
Plan (Planificación): Definición de requisitos, tareas y sprints (ej. Jira, GitHub Projects).

Code (Codificación): Escritura del software y control de versiones del código (ej. Git).

Build (Construcción/Compilación): Empaquetado del software o generación de artefactos e imágenes (ej. Gradle, Maven, Docker build).

Test (Pruebas): Ejecución automatizada de pruebas unitarias, de integración y de seguridad.

Release (Preparación de entrega): Validación de versiones estables listas para subir a producción.

Deploy (Despliegue): Publicación del servicio o aplicación en el entorno destino (ej. Kubernetes, AWS, servidores on-premise).

Operate (Operación): Mantenimiento en activo, escalado del servicio y gestión de configuración (ej. Ansible, Terraform).

Monitor (Monitorización): Seguimiento del rendimiento, alertas y análisis de logs (ej. Grafana, Graylog, Prometheus).
