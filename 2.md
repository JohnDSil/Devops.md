# 2.- Fases de DevOps

### El ciclo de vida de DevOps se representa de manera continua e interactiva mediante el bucle infinito:

* 1. Plan (Planificación): Definición del alcance técnico, gestión de tareas e incidencias mediante metodologías ágiles (Jira, GitHub Issues o Trello).

* 2. Code (Codificación): Desarrollo del código fuente y control de versiones distribuido con Git. Uso de ramas (branches) y revisiones colaborativas de código mediante Pull Requests.
   
* 3. Build (Construcción/Compilación): Transformación del código fuente en artefactos ejecutables o imágenes de contenedores. Herramientas: Gradle, Maven, Docker build.

* 4. Test (Pruebas Automatizadas): Ejecución desatendida de pruebas unitarias, de integración, análisis estático de vulnerabilidades (SAST) y pruebas de rendimiento.

* 5. Release (Gestión de Versiones): Empaquetado, etiquetado de versiones estables (ej. v2.1.0) y almacenamiento en repositorios de artefactos (Sonatype Nexus, Harbor).
  
* 6. Deploy (Despliegue): Publicación controlada en entornos de producción o pruebas mediante arquitecturas cloud (AWS, Azure, OpenStack) o clústeres de contenedores (Kubernetes).

* 7. Operate (Operación y Mantenimiento): Gestión de configuraciones, escalado de recursos y mantenimiento del servicio activo con herramientas de automatización (Ansible, Chef).

* 8. Monitor (Monitorización y Observabilidad): Recolección continua de métricas de rendimiento, análisis centralizado de logs y generación de alertas operativas (Grafana, Graylog, Prometheus).
