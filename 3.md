# 3.- Herramientas CI/CD
El núcleo operativo de DevOps reside en la implementación del pipeline de CI/CD:

* CI (Continuous Integration - Integración Continua):
Obliga a fusionar los cambios de código frecuentemente en la rama principal. Cada integración dispara una compilación y una batería de pruebas de forma automática. Si algo falla, el pipeline aborta la ejecución antes de contaminar la base de código.

* CD (Continuous Delivery - Entrega Continua):
Asegura que el artefacto resultante de CI esté siempre listo para ser puesto en producción en cualquier momento, requiriendo únicamente una aprobación manual final.

* CD (Continuous Deployment - Despliegue Continuo):
Todo cambio que supera con éxito la fase de pruebas automáticas pasa a producción de forma autónoma e inmediata, sin aprobación humana previa.

## Herramientas destacadas

### GitLab CI/CD:

Motor nativo integrado en la plataforma GitLab.

Se configura mediante un archivo declarativo .gitlab-ci.yml.

Excelente gestión de runners locales o en la nube para ejecutar contenedores de trabajo.

### Jenkins:

Servidor de automatización de código abierto altamente extensible mediante plugins.

Define pipelines complejos basados en código a través de scripts Jenkinsfile (sintaxis declarativa o scripted en Groovy).

### GitHub Actions:

Solución integrada directamente en los repositorios de GitHub.

Disparada por eventos de Git (push, pull_request, release).

Reutiliza módulos públicos de la comunidad (actions) para empaquetado y conexión a proveedores cloud.

### SonarQube:

Plataforma de inspección continua de calidad y seguridad de código.

Actúa como barrera (Quality Gate) en el pipeline: bloquea el paso si se detecta código duplicado, deuda técnica crítica o vulnerabilidades conocidas.
